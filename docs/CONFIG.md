# Configuration reference

Six files under `BepInEx/config/`. Each one is generated by its plugin on first run, so the shipped copy in `payload/config/` is only a starting point: the installer writes it only when no file exists.

Edit by hand, or use `配置面板.cmd` (config editor). The editor writes a `.bak` per save and keeps the original line endings.

> 中文版：[zh-CN/CONFIG.md](zh-CN/CONFIG.md)

## vrk.flatfps.cfg — no-VR core / camera / input

### `[General]`

| Key | Default | Meaning |
| --- | --- | --- |
| `ForceFlatMode` | `true` | Let the game continue without a headset (patches `InitScene2.CheckHMD`) |
| `LockCursor` | `true` | Keep the pointer in the window while playing |
| `CursorHoldKey` | `LeftAlt,RightAlt` | Hold to release the pointer (comma separated, empty = never) |

### `[Camera]`

| Key | Default | Meaning |
| --- | --- | --- |
| `EyeHeightEnabled` | `true` | Plant the no-VR eye at a standing height |
| `EyeHeight` | `1.28` | Metres. `PageUp`/`PageDown` change it live in first person |
| `MenuSceneCameraFix` | `true` | Freeze the third-person controller on menu/loading scenes (it used to push the camera 1.5 m forward and move the VR menus out of view) |
| `GameScenes` | 22 scene names | Which scenes count as "in game" (comma separated) |
| `ViewToggle` / `ViewToggleKey` | `true` / `F` | Cycle first person → third person → free camera |
| `FirstPersonRotateRig` | `true` | Turn the player rig (not just the camera) so the game agrees where you are looking |
| `FirstPersonMoveSpeed` | `2` | m/s while walking in first person |
| `FreeMoveSpeed` / `FreeSprintMultiplier` | `3` / `3` | Free camera speed, and the Shift multiplier |
| `ThirdPersonDistance` | `1.5` | Ring radius of the original third-person camera |
| `SyncGameGazeCamera` | `true` | Point the game's own gaze rays at the eye you actually look through |
| `GazeLookDistance` | `3.5` | How far the game's gaze checks reach |
| `LookDistance` | `3.5` | `PlayerLookingCheck.raycastDis` — how close you must stand for "being looked at" reactions |

### `[Input]`

| Key | Default | Meaning |
| --- | --- | --- |
| `UseFpsKeys` | `true` | WASD instead of the arrow keys, digits instead of the numpad |
| `InteractKey` | `E` | Key that drives the game's hand/gaze interaction |
| `GazeGrabDistance` | `2.5` | Grab reach for gaze/touch interaction (the game hardcodes 1.5) |
| `MouseHandGrab` / `MouseHandTeleport` | `true` / `true` | Left button drives the game's `Hand`: teleport it onto the aim point and grab |
| `MouseHandReach` | `5` | Ray length for that grab |
| `MouseBodyCaress` | `true` | Left button also triggers body caress grabbing |
| `ForceNonController` | `true` | Write `controlType = 0` so the game enables mouse/keyboard interaction paths |
| `ForceEnableGaze` | `true` | Force `enableGaze` on the touch manager |
| `DisableIme` | `true` | Detach the IME from the game window (WASD used to open the Chinese IME) |
| `DirectMenuClick` / `PhysicsClick` / `ClickInGame` | `true` | Three click paths: UI rectangle test, physics raycast + event dispatch, enabled in gameplay |
| `ClickProc` | `true` | Fall back to `InteractiveCommandController.InteractiveProc` |
| `ClickVRItem` | `false` | Also fire `VRInteractiveItem.Click` (off by default: the game already does it, it caused double clicks) |
| `UiPointerSpace` | `Auto` | Which pixel space the UI receives (`Auto` = per canvas) |
| `LegacyUiBridge` | `false` | Old `EventSystem` injection. Off: it made `IllusionCamera.OnUI` permanently true and swallowed dragging |
| `MenuCursorLock` | `false` | Keep the pointer locked on menu scenes too |
| `KeepOvrInput` | `true` | Do not disable the game's own input modules |

### `[Visual]`

| Key | Default | Meaning |
| --- | --- | --- |
| `AlwaysShowGazeRing` | `true` | Keep the gaze ring visible instead of letting the game fade it out |
| `GazeRingMode` | `Aim` | `Aim` snaps the ring to whatever you look at, `Center` pins it to the screen centre |
| `GazeRingMaxDistance` | `8` | Ray length for that (8 m reaches walls and furniture) |
| `GazeRingHideWhenNoHit` | `true` | Hide the ring when nothing is hit instead of floating it in mid air |
| `GazeRingDistance` | `1.5` | Distance used in `Center` mode |
| `HideGazeRing` | `false` | Remove the ring completely |
| `Crosshair` / `CrosshairSize` / `CrosshairAlpha` | `false` / `56` / `0.85` | The original crosshair image (off by default — the gaze ring replaces it) |
| `CrosshairFirstPersonOnly` | `false` | Draw it in first person only |
| `HoverReticle` | `true` | Corner brackets + "E" hint over interactable objects |

### `[Fade]` — white screen watchdog

| Key | Default | Meaning |
| --- | --- | --- |
| `ClearPanelOnAwake` | `true` | Clear the opaque fade panel as soon as it is created (root cause of the stock white screen) |
| `RepairStuckFade` | `true` | Detect a fade that never finishes and clear it |
| `StuckFadeSeconds` | `2` | How long the alpha must stay unchanged before it counts as stuck |
| `CoveredSceneSeconds` | `8` | Fully covered screen for this long on the same scene = repair |
| `HardKillSeconds` | `3` | After two repairs that keep coming back, disable the panel for the whole session |

### `[Help]`

| Key | Default | Meaning |
| --- | --- | --- |
| `ShowOnStart` | `true` | Show the key reference on entering a scene |
| `AutoHideSeconds` | `5` | Auto-hide delay (`0` = stay) |
| `Hotkey` | `F7` | Show/hide |
| `Scale` | `1` | Font scale |

### `[Diagnostics]`

| Key | Default | Meaning |
| --- | --- | --- |
| `Verbose` | `false` | Chatty logging |
| `FrameGapSeconds` | `1.5` | Log a warning for frames longer than this |
| `GazeAimLog` | `true` | Log gaze grabs |
| `InteractionLog` | `false` | Log every left click and what it hit |
| `GazeRingLog` / `CenterProbe` / `ProbeDelay` | `false` / `true` / `4` | Ring target logging, screen-centre probe after N seconds |
| `DumpKey` | `F10` | Dump cameras/canvases/UI on demand |
| `SaveFrames` / `MaxShots` | `false` / `3` | Save `vrk_frame_<scene>_<n>.png` screenshots |

## vrk.upscale.cfg — FSR1

| Key | Default | Meaning |
| --- | --- | --- |
| `Enabled` | `true` | Master switch (inactive in VR mode) |
| `Mode` | `RenderScale` | `RenderScale` renders below native and upscales; `Sharpen` is RCAS at native resolution |
| `Scale` | `0.85` | Render scale (0.85 → 2176×1224 → 2560×1440) |
| `Sharpness` | `0.2` | RCAS sharpness, 0…1 |
| `NativePass` | `false` | `true` calls `vrkup.dll` (EASU+RCAS). Off = Unity's own upscale; the native layer is disabled until its render-target lifetime fix is re-verified |
| `SanitySeconds` | `5` | Safety blit interval |
| `OutputWidth` | `0` | Force a fixed output width (`0` = follow the screen) |
| `StatusKey` / `Verbose` | `F9` / `false` | Status dump / chatty logging |

## vrk.perf.cfg — frame pacing

| Key | Default | Meaning |
| --- | --- | --- |
| `VSync` | `0` | `-1` leave alone, `0` off, `1` on, `2` every second frame |
| `TargetFrameRate` | `0` | `-1` leave alone, `0` uncapped |
| `PinOvrRecommendedMsaa` | `true` | Stop `OVRManager` from resetting `QualitySettings.antiAliasing` every frame |
| `CameraReport` / `Verbose` | `false` / `false` | Diagnostic dumps |

## vrk.prewarm.cfg — loading prewarm

| Key | Default | Meaning |
| --- | --- | --- |
| `Enabled` | `true` | Master switch |
| `WarmShaders` | `false` | `Shader.WarmupAllShaders()` — Unity 5.4 already warms 145 variants at startup, so this mostly duplicates it |
| `WarmMaterials` / `WarmTextures` | `true` / `true` | `Material.SetPass(0)` and `Texture.GetNativeTexturePtr()` over the scene |
| `SkipLoadingScenes` | `false` | Skip prewarm on the loading screens |
| `FrameBudgetMs` / `TotalBudgetMs` | `6` / `2000` | Per-frame and total budget |

## vrk.texplus.cfg — textures

| Key | Default | Meaning |
| --- | --- | --- |
| `FullResolution` | `true` | `masterTextureLimit = 0` |
| `AnisoLevel` | `16` | Anisotropic filtering level for every texture |
| `ForceTrilinear` | `true` | Bilinear → trilinear |
| `MipMapBias` | `0` | Mip bias |
| `RescanSeconds` | `0` | Periodic rescan (`0` = only on scene load) |
| `PerFrame` | `48` | Textures processed per frame, keeps the spike small |

## vrk.unlock.cfg — content unlock

| Key | Default | Meaning |
| --- | --- | --- |
| `Enabled` | `true` | Master switch |
| `UnlockAll` | `true` | Call the game's own `ALLClearData()` |
| `UnlockStory` / `UnlockInteractive` / `UnlockLessons` | `true` | Partial unlocks, used when `UnlockAll = false` |
| `FlushToDisk` | `true` | Write the save immediately |
| `RetrySeconds` / `MaxAttempts` | `2` / `30` | Retry policy while the save object is not ready |
| `Verbose` | `false` | Per-step logging |

> Unlocking writes into your save (`UserData/save/save.dat`). Back it up once before the first run if you care about the original progress.
